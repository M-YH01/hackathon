# 약속 날씨 판결기

"오늘 약속, 가도 될까?" 기상청 단기예보와 에어코리아 초미세먼지 예보, 그리고 내 사정 한 줄로 **강행 / 실내로 변경 / 미루기**를 판단하고, 상대와의 관계에 맞는 **보낼 말 3종**까지 만들어 주는 서비스입니다.

## 1. 문제와 대상 사용자
- **대상:** 야외 약속을 앞두고 날씨가 마음에 걸리지만 "미루자"는 말을 꺼내기 어려운 사람.
- **상황과 어려움:** 날씨가 어느 정도면 미뤄도 되는지 기준이 없고, 미루자는 말도 미안하고 어색해서 결정이 늦어져 당일 취소가 되거나 무리해서 나가게 된다.
- **이 서비스가 채우는 빈칸:** 날씨 앱이 보여 주지 않는 "이 약속을 미뤄도 되는 정도인가"의 판단 기준, 실내 대안 제안, 전할 말.

## 2. 공공데이터 확인

| 항목 | 기상청 단기예보 | 에어코리아 대기오염정보 |
|---|---|---|
| 제공처 | 기상청 (공공데이터포털) | 한국환경공단 (공공데이터포털) |
| 출처 링크 | https://www.data.go.kr/data/15084084/openapi.do | https://www.data.go.kr/data/15073861/openapi.do |
| 사용 기능 | 단기예보 조회(`getVilageFcst`) | 대기질 예보통보 조회(`getMinuDustFrcstDspth`) |
| 사용 항목 | 기온(TMP, 일 최고 TMX, 일 최저 TMN), 강수확률(POP), 강수형태(PTY), 1시간 강수량(PCP), 적설(SNO), 풍속(WSD) | 초미세먼지(PM25) 예보 등급 |
| 기준일 | 호출 시점의 가장 최근 발표(`base_date`, `base_time`)를 화면에 표시 | 예보통보 발표 시각(`dataTime`)을 화면에 표시 |
| 이용조건 | 공공데이터포털 이용약관과 해당 API 페이지의 이용허락범위를 따른다. 인증키는 서버 환경 변수에만 둔다. | 같음 |
| 트래픽(개발계정) | 10,000 | 500 |

- **예보 범위:** 오늘~글피(4일). 4일째부터는 강수량·풍속이 정성 코드로 제공되어 정밀도가 낮아 제외했다.
- **시험 데이터와 공공데이터의 구분:** 키가 없거나 `USE_FIXTURES=1`이면 고정된 시험 값을 쓰며 화면에 "데이터: 시험 데이터"라고 표시한다. "예보 대신 값을 직접 입력"을 켜면 "직접 입력(시험용)"으로 표시한다. 공공데이터를 실제로 호출했을 때만 "데이터: 공공데이터"로 표시한다.
- **사용하지 않은 데이터:** 기상청 생활기상지수의 체감온도 서비스는 2026-05-11에 종료되어 쓰지 않고, 기온과 풍속으로 판단한다.

## 3. AI 역할 정의

| 단계 | 입력 | 출력 | AI를 쓰는 이유 |
|---|---|---|---|
| 개인 사정 분류 | 사용자가 적은 한 줄("오늘 나가기 너무 귀찮아") | 가족·응급 / 심한 건강 문제 / 시험·마감 / 업무·야근 / 약속 겹침 / 이동 곤란 / 가벼운 컨디션 / 감정 / 단순 귀찮음 / 기타 중 하나 | 자유 문장의 뜻을 정규식만으로는 정확히 가르기 어렵다. |
| 판결문·메시지 작성 | 규칙이 계산한 판결·점수·이유, 상대와의 관계, 약속 시각 | 판결문 1개(사용자에게 설명), 정중한 / 가벼운 / 단호한 버전 문장 3종 | 같은 판결도 친구·동료·상사에 맞는 말투와 표현이 달라야 한다. |

**AI가 하지 않는 일과 안전장치**
- 점수와 판결은 **규칙이 계산**한다. AI는 숫자를 바꾸지 못하고, 개인 사정 점수는 분류별로 고정된 값(최대 +55)이라 AI가 분류만 하고 점수는 표에서 정해진다. 단순 귀찮음은 +5라 "귀찮음"만으로는 미루기가 나오지 않는다.
- AI가 쓴 문장 속 숫자가 규칙이 준 사실(이유·시각·점수)에 없으면 그 문장을 버리고 규칙 문장으로 대신한다.
- 사용자가 적은 사정 문장 안의 지시는 따르지 않는다. 분류 결과는 정해진 값만 받는다.
- 무기력·우울 같은 안부 표현은 **AI로 보내지 않고** 규칙이 먼저 걸러 판결 대신 안부 문구를 보여 준다.
- AI 키가 없거나 호출이 실패하면 규칙 기반 문장으로 동작한다. 화면에 "사정 분류: AI/규칙", "판결문: AI/규칙 문장", "메시지: AI/규칙 문장"으로 어느 쪽이 썼는지 표시한다.
- 개인 사정 한 줄은 저장하지 않는다. 다만 AI를 쓰면 입력이 Google AI Studio 무료 등급에서 서비스 개선에 쓰일 수 있어 화면에 건강 정보를 적지 말라고 안내한다.

**판결 규칙(요약)**

| 항목 | 기준 | 점수 |
|---|---|---|
| 최고기온 | 39℃ 이상 / 35℃ 이상 / 33℃ 이상 | +45 / +30 / +15 |
| 최저기온 | -15℃ 이하 / -12℃ 이하 / -8℃ 이하 | +40 / +30 / +15 |
| 강수확률 | 80% 이상 / 60% 이상 / 40% 이상 | +40 / +25 / +10 |
| 1시간 강수량(PCP) | 30mm 이상 / 15mm 이상 / 3mm 이상 | +40 / +30 / +15 |
| 적설(SNO) | 5cm 이상 / 1cm 이상 | +40 / +25 |
| 강수형태(PTY) | 눈 또는 비·눈 | +10 |
| 풍속 | 20m/s 이상 / 14m/s 이상 / 9m/s 이상 | +45 / +30 / +10 |
| 초미세먼지 예보 | 매우나쁨 / 나쁨 | +45 / +15 |
| 실내 약속 | 날씨 점수를 40%만 반영 | |
| 중요한 약속 | 날씨 점수가 40 미만(불편한 정도)일 때만, 개인 사정 점수는 그대로 | 날씨 점수 −15(최대) |

**개인 사정 점수(10분류)**

| 분류 | 예시 | 점수 |
|---|---|---|
| 가족·응급 | 장례, 경조사, 돌봄, 응급 | +55 |
| 심한 건강 문제 | 고열, 병원, 부상 | +50 |
| 시험·마감 | 시험, 마감, 발표, 면접 | +45 |
| 업무·야근 | 갑작스러운 업무, 야근 | +40 |
| 약속 겹침 | 다른 약속과 시간 충돌 | +40 |
| 이동 곤란 | 교통 파업, 차량 고장 | +30 |
| 가벼운 컨디션 | 피곤, 약한 몸살 | +15 |
| 감정 | 스트레스, 기분 문제 | +15 |
| 단순 귀찮음 | 가기 싫음 | +5 |
| 기타 / 없음 | | 0 |

조정 필요도 0~39 강행, 40~69 실내로 변경, 70~100 미루기. 단, 40~69점이어도 개인 사정 점수가 날씨 점수보다 크면 장소를 바꿔도 해결되지 않으므로 미루기로 본다. 기준값은 팀이 정한 값이며 기상청 특보 기준을 단순화했다. 최고기온 39℃는 프로야구가 폭염중대경보(최고기온 39℃ 또는 체감온도 38℃ 이상) 시 경기 취소를 결정할 수 있도록 한 기준을 참고했다. 초미세먼지 등급(좋음 0~15, 보통 16~35, 나쁨 36~75, 매우나쁨 76 이상)은 환경부 기준이다.

## 4. 실행·시연 준비

### 로컬 실행 (Node.js 20.6 이상)
1. `.env.example`을 복사해 `.env`를 만들고 키를 채운다. (`DATA_GO_KR_KEY` = 공공데이터포털 일반 인증키, `GEMINI_API_KEY` = 선택)
2. `npm start` 를 실행하고 http://localhost:3000 을 연다.
3. 키 없이 화면만 보려면 `npm run start:demo` (시험 데이터로 동작).

### Vercel 배포
`public/`이 화면, `api/verdict.js`가 서버 함수다. Vercel 프로젝트 설정의 Environment Variables에 `DATA_GO_KR_KEY`(와 선택으로 `GEMINI_API_KEY`)를 넣고 배포한다. `vercel.json`으로 서버 지역을 서울(`icn1`)로 고정했다. **키는 저장소나 화면에 넣지 않는다.**

### 대표 입력 (화면의 "예보 대신 값을 직접 입력" 아래 버튼)

| 대표 입력 | 약속 | 값 | 개인 사정 | 조정 필요도 | 판결 |
|---|---|---|---|---|---|
| 맑은 날 카페 | 실내, 친구 | 24℃, 강수 10%, 풍속 2, 미세먼지 좋음 | 없음 | 0 | 강행 |
| 폭염 야외 | 야외, 친구 | 최고 39℃ | 없음 | 45 | 실내로 변경 |
| 호우 야외 | 야외, 동료 | 강수 90%, 풍속 10 | 없음 | 50 | 실내로 변경 |
| 미세먼지 매우 나쁨 | 야외, 친구 | 초미세먼지 매우나쁨 | 없음 | 45 | 실내로 변경 |
| 귀찮음만 있음 | 야외, 친구 | 맑음 | 오늘 나가기 너무 귀찮아 | 5 | 강행 |
| 업무 충돌 | 야외, 동료 | 맑음 | 갑자기 야근이 생겼어 | 40 | 미루기 |
| 폭염+호우+몸살 | 야외, 상사 | 36℃, 강수 90% | 몸살 기운이 있어 | 85 | 미루기 |

### 자동 시험
`npm test` — 규칙 점수, 사정 분류, 기상청·에어코리아 응답 처리(모의 응답), AI 응답 검증과 대체 동작, API 입력 검증을 확인하는 36개 시험이 있다.

## 5. 결과·한계

**확인한 것**
- 위 대표 입력이 표와 같은 점수·판결을 낸다(자동 시험).
- 키 없이 시험 데이터로 끝까지 동작하고, 시험 데이터임을 화면에 표시한다.
- AI 응답이 규칙 밖의 숫자를 쓰거나 형식이 틀리면 규칙 문장으로 대신한다(모의 응답으로 확인).

**확인하지 못한 것 (정직하게 적는다)**
- 실제 공공데이터 호출은 모의 응답으로만 시험했다. 인증키로 실제 응답을 받아 요청 변수와 응답 구조가 문서와 같은지는 키 연결 후 확인해야 한다.
- 실제 AI 호출도 키 연결 후 확인해야 한다.
- 판결의 "정확성"(실제로 미루는 것이 옳았는지)은 검증하지 않았다. 점수 구간은 임의로 정한 값이다.

**한계**
- 지역은 19개 도시(시청·도청 소재지)만 지원한다. 위경도를 기상청 변환식으로 격자로 바꾸며, 같은 시·군 안에서도 동네에 따라 예보가 다를 수 있다.
- 강수량(PCP)·적설(SNO)은 "30~50mm" 같은 범위·"이상" 값을 아래쪽 값으로 읽어 과장하지 않는다. 이 값의 실제 응답 형식은 배포 후 확인이 필요하다.
- 초미세먼지는 지역 단위 등급이라 동네 차이를 반영하지 못한다.
- 에어코리아 응답이 느려 시간 초과가 나면, 같은 지역·날짜로 최근 6시간 안에 성공한 값을 서버 메모리에서 대신 쓰고 화면에 알린다. 서버가 새로 뜬 첫 요청은 대체할 값이 없어 미세먼지가 빠질 수 있다.
- 예보는 바뀔 수 있으며 판결은 참고용이다.
- 상대와의 관계는 3가지로 단순화했다.
- 개인 사정 분류는 10가지로 나눴지만 실제 사정의 무게는 사람마다 다르다. 점수는 팀이 정한 값이며, AI가 다르게 분류하면 점수도 달라진다.
